# Movies-Project
A complete end-to-end Data Analytics &amp; Business Intelligence project based on the entertainment industry dataset (movies.csv). This project explores movie performance, genre trends, profitability analysis, SQL-based ETL pipelines, Excel EDA, interactive Power BI dashboards, and AI-powered automation workflows using n8n + GenAI.

# CinemaScope Analytics

## Project Overview
This project analyzes movie industry data using SQL, Excel, Power BI, and GenAI automation workflows.

## Objectives
- Perform ETL using SQL
- Analyze movie trends
- Build Power BI dashboard
- Create AI-powered automation workflows

## Tech Stack
- SQL
- Excel
- Power BI
- Python
- n8n
- GenAI

## Project Structure
- SQL Queries
- Excel Analysis
- Power BI Dashboard
- n8n Workflow JSON
- Screenshots

## Dashboard Features
- Genre analysis
- Financial analysis
- Director & star analysis
- Profitability tracking
- Interactive slicers

## Automation Workflows
### 1. Automated Movie Insight Generator
Generates AI summaries from dashboard KPIs.

### 2. AI Movie Recommendation System
Explains why movies succeed or fail using GenAI.

## Key Insights
- Action genre generated highest profits
- Family movies showed highest ROI
- Budget and gross earnings are positively correlated
